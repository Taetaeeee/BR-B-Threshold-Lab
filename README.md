# Threshold Lab — 로그인 이상 탐지 실험실

**SKT ALEPH 마지막 과제 B (BR-B / 13번), 독립 실행 시제품 v0.1**  
연구 출처: 김봉경, 「로그인 실패 횟수 임계값이 이상 접속 탐지 성능에 미치는 영향」, 2026-11-10 (T10 C안 연구).

## 누구를 어떻게 돕는가
보안 담당자와 보안 학습자가 로그인 실패 횟수 탐지 규칙의 **공격 누락(FNR)**과 **정상 오탐(FPR)** 사이의 상충관계를 이해하고, 예시 이벤트에 같은 판정 규칙을 적용해 보도록 돕습니다.

## 로컬 실행: 3단계

1. 이 ZIP을 임의의 새 폴더에 압축 해제합니다.
2. 해당 폴더에서 Python 3를 사용해 `python -m http.server 8000`을 실행합니다. (`python` 대신 `python3`가 필요한 환경도 있습니다.)
3. 브라우저에서 `http://localhost:8000/`을 엽니다. **로그인, API 키, 패키지 설치가 필요하지 않습니다.**

메뉴에서 **연구 비교 → 탐지 실습 → 비용 분석**을 순서대로 사용합니다. Chrome/Edge/Firefox의 최신 버전을 권장합니다.

## 수행할 작업 세 가지

1. **연구 비교** — 임계값 4~10회와 본 실험/사후 분포 변경을 선택해 혼동행렬과 FNR/FPR 변화를 확인합니다.
2. **탐지 실습** — 기본 제공하는 예시 CSV 또는 직접 만든 **가상 데이터**를 분석합니다. IP와 UTC 기준 5분 구간별로 실패 횟수를 세고 현재 임계값으로 경보를 결정합니다.
3. **비용 분석** — 가정한 공격 구간 비율과 미탐 비용 가중치를 바꾸고 임계값별 기대 손실을 비교합니다. 보고서 TXT를 저장할 수 있습니다.

## 연구 결과가 기능으로 연결된 위치

| 논문 내용 | 실제 구현 | 관련 파일 |
|---|---|---|
| 본 실험 임계값 4~10회별 TP/FN/FP/TN (표 1) | 임계값 변경 시 지표·그래프·혼동행렬 갱신 | `engine.mjs`, `app.mjs` |
| 사후 탐색적 분포 변경 결과 (표 2) | 본 실험과 사후 결과 전환 (7회 FPR 0% ↔ 38.86%) | `engine.mjs`, `app.mjs` |

**데이터 표기에 관한 중요 사실:** 연구의 진짜 원시 로그 `logs.csv`와 `windows.csv`, `labels.csv`를 이 시제품 ZIP에 포함하지 않았습니다. 연구 패널은 **논문에 발표된 정확한 집계 숫자**를 사용합니다. 탐지 실습에서 사용하는 12개 구간/82개 이벤트는 **시연용으로 별도 생성한 가상 자료**입니다. 연구의 1,000개 구간을 재현한 것이라고 주장하지 않습니다.

## 입력 규약

한 줄에 사건 한 건이며, 쉼표로 나눈 다음 네 열만 받습니다:

```csv
timestamp_utc,ip,result,label
2026-11-10T00:00:00Z,192.0.2.1,failure,attack
2026-11-10T00:01:00Z,192.0.2.1,success,attack
```

- `timestamp_utc`: UTC 날짜/시간, 초 단위 `YYYY-MM-DDTHH:mm:ssZ`
- `ip`: IPv4. 예시는 RFC 5737 문서용 주소 사용
- `result`: `failure` 또는 `success`
- `label`: 평가용 정답 `attack` 또는 `normal`. 실제 탐지에는 사용하지 않음
- 동일 IP와 UTC 5분 고정 구간에 다른 정답 라벨을 혼합하면 해당 행을 제외하고 안내합니다.
- 유효하지 않은 행은 **건별 격리**하며, 유효한 나머지 행은 계속 분석합니다.
- 최대 3,000개의 데이터 행을 처리합니다. CSV 따옴표/쉼표 포함 필드, IPv6, 실제 로그인 서비스 연동은 지원하지 않습니다.

**개인정보 주의:** 실제 운영 로그, 고객 데이터, 실명, 비밀 키, 실제 IP 식별 정보 등을 입력하지 마세요. 서버/API 업로드 기능이 없고 입력은 브라우저 메모리에서만 분석합니다. 보고서에는 이벤트 원본을 포함하지 않습니다.

## 연구 한계

- 논문 자료는 합성 데이터입니다. 실제 방어율, 실제 공격 발생률, 기업 내 비용을 측정한 값이 아닙니다.
- 본 실험에서 7회 기준 오탐 0%는 **정상 구간의 실패 횟수를 6회 이하로 생성한 설계**에 의존하며, 사후 탐색적 분포에서는 7회 FPR 38.86%였습니다.
- 사후 분석은 별도 탐색 실험이지 원래 가설의 재검증이 아닙니다.
- 이 앱은 탐지 원리를 배우는 도구이며 **운영 환경에 바로 적용하는 보안 제품은 아닙니다.**
