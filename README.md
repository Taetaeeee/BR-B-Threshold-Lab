## 누구를 어떻게 돕는가

보안 담당자와 보안 학습자가 **로그인 실패 횟수 임계값에 따라 공격 누락(FNR)과 정상 오탐(FPR)이 어떻게 바뀌는지** 이해하고, 가상 로그에 탐지 규칙을 적용해볼 수 있도록 돕습니다.

## 사용자가 할 수 있는 작업 3가지

1. **연구 비교:** 임계값 4~10회와 본 실험/사후 분포 변경 조건을 전환해 FNR·FPR·F1·혼동행렬을 비교합니다.
2. **로그 탐지 실습:** 예시 CSV 또는 가상의 사용자 입력을 IP별 UTC 5분 구간으로 묶어 경보를 판정합니다.
3. **비용 분석:** 공격 발생률과 미탐 비용을 가정해 임계값별 상대 기대 비용을 비교하고 TXT를 저장합니다.

## 연구 결과가 기능으로 연결되는 부분

| 논문 결과 | 앱 기능 | 구현 |
|---|---|---|
| 본 실험 표 1: 4~10회 임계값별 TP/FN/FP/TN | 임계값 변경 시 지표·그래프·혼동행렬 갱신 | `engine.mjs`, `app.mjs` |
| 본 실험 6→5회: FNR 22.33→9.67%, FPR 14.57→29.00% | 첫 화면 연구 핵심 결과 및 가설 미지지 설명 | `index.html`, `engine.mjs` |
| 사후 탐색적 표 2: 7회 FPR 38.86% | 본 실험의 7회 FPR 0%와 비교 가능 | `engine.mjs`, `app.mjs` |
| 동일 IP·UTC 5분 간 실패 횟수 이상이면 경보 | 입력된 가상 인증 이벤트 탐지 | `engine.mjs` |
| 가정 발생률·상대 오탐/미탐 비용의 기대 비용 | 조건별 시나리오 민감도 분석 | `engine.mjs`, `app.mjs` |

**해석상의 한계:** 연구와 앱의 집계값은 합성 데이터 기반입니다. 실제 운영 서비스의 탐지율이나 최적 보안 정책을 보장하지 않습니다. 5%p 오탐 증가 허용폭은 외부 표준 권고가 아니라 연구 설계에서 제안된 가정입니다.

**원자료 구분:** 논문 원문 PDF와 논문에 보고된 집계 수치는 포함합니다. 그러나 연구에 사용한 원시 CSV(`logs.csv`, `windows.csv`, `labels.csv`)는 앱에 포함하지 않습니다. 입력 실습용 예시는 별도 생성한 가상 데이터로, 연구의 1,000구간을 재현한 자료가 아닙니다.

## 실행 (로그인·API 키·빌드 불필요)

1. 프로젝트 압축을 새 폴더에 해제합니다.
2. 그 폴더에서 `python -m http.server 8000` 실행 (환경에 따라 `python3`).
3. `http://localhost:8000/`에 접속하여 연구 비교 → 탐지 실습 → 비용 분석을 사용합니다.

메인 화면의 **최종 논문 PDF 열기**를 누르면 `research/T10_paper.pdf`가 새 탭에 열립니다. 브라우저 설정에 따라 다운로드될 수 있습니다.

## CSV 입력 규격

```csv
timestamp_utc,ip,result,label
2026-11-10T00:00:00Z,192.0.2.1,failure,attack
2026-11-10T00:01:00Z,192.0.2.1,success,attack
```

- `timestamp_utc`: UTC 시간 `YYYY-MM-DDTHH:mm:ssZ`
- `ip`: IPv4. 문서용 예약 주소 활용 권장
- `result`: `failure` / `success`
- `label`: `attack` / `normal` (평가에만 사용, 탐지에 미사용)
- 최대 3,000개 데이터 행을 분석합니다. 오류 행은 격리되며 다른 정상 행은 분석됩니다.
- 실제 고객·직원 로그, 개인정보, API 키를 입력하지 마세요. 데이터는 브라우저에서만 처리하며 서버로 전송하지 않습니다.

## 확인 방법

1. **어디로:** 공개 앱 URL 또는 로컬 실행 주소로 접속합니다.
2. **3단계:** `최종 논문 PDF 열기` → `임계값 6회에서 5회로 변경` → `탐지 실습`에서 예시 데이터를 분석합니다.
3. **통과 기준:** PDF 7페이지 표시, FNR/FPR 변화, 탐지 결과 및 오류 없는 실행을 확인합니다.
4. **안 될 때:** PDF가 404면 `research/T10_paper.pdf`가 GitHub에 업로드됐는지 확인하고 재배포합니다. 수치 미표시 시 브라우저 콘솔을 확인합니다.
